# 語音導覽（白牆導覽版）

把這個資料夾裡的所有檔案上傳到 GitHub 倉庫的根目錄，保持資料夾結構不變：

```
index.html
audio/A.mp3  audio/B.mp3  audio/C.mp3
works/*.jpg
```

## 白牆導覽怎麼運作

- 每支手機打開網頁時隨機抽一軌：A : B : C = 3 : 2 : 2，不記住上次的結果。
- 觀眾拍到白牆（或從選單的作品列表點〈圓〉），導覽員會顯示倒數；所有手機依時鐘每 2 分鐘開一場，時間到一起開始播放各自的音軌。
- 播放中會和共同時間對齊，誤差超過 1.5 秒就校正。
- 音檔讀不到時，改用手機語音在對應秒數朗讀文稿。

## 網址代碼

- 指定軌：網址後加 `#q7`（A）、`#m2`（B）、`#r5`（C）
- 主辦者設定：網址後加 `#ctl-7`，可以查看本機的軌、下一場時間，並切換軌

## 要修改的地方（都在 index.html 的 DATA 區段）

- `event.cycle`：每幾秒開一場，目前 120。
- `event.scripts`：語音朗讀備用模式的文稿與秒數。換新音軌後一起更新。
- 白牆的參考照片 `works/wall_a.jpg`、`works/wall_b.jpg` 目前是示意圖，請換成在展場實拍的白牆照片（不同角度、距離 4～8 張），並把檔名寫進 `refs`。
- 換新音軌時，直接用同樣的檔名覆蓋 `audio/A.mp3`、`audio/B.mp3`、`audio/C.mp3`。
