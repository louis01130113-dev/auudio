# 語音導覽（白牆導覽版）

把這個資料夾裡的所有檔案上傳到 GitHub 倉庫的根目錄，保持資料夾結構不變：

```
index.html
audio/A.m4a  audio/B.m4a  audio/C.m4a
works/*.jpg
```

## 白牆導覽怎麼運作

- 每支手機打開網頁時隨機抽一軌：A : B : C = 3 : 2 : 1，不記住上次的結果。
- 觀眾拍到白牆（或從選單的作品列表點〈圓〉），導覽員會顯示倒數；所有手機依時鐘每 2 分鐘開一場，時間到一起開始播放各自的音軌。
- 播放中會和共同時間對齊，誤差超過 1.5 秒就校正。
- 完全不使用機器語音：所有聲音都是藝術家本人的錄音；音檔讀不到時，只在對應秒數把文稿顯示成文字。

## 網址代碼

- 指定軌：網址後加 `#q7`（A）、`#m2`（B）、`#r5`（C）
- 主辦者設定：網址後加 `#ctl-7`，可以查看本機的軌、下一場時間，並切換軌

## 要修改的地方（都在 index.html 的 DATA 區段）

- `event.cycle`：每幾秒開一場，目前 120。
- `event.scripts`：音檔讀不到時顯示的文稿與秒數。換新音軌後一起更新。
- 換新音軌時，直接用同樣的檔名覆蓋 `audio/A.m4a`、`audio/B.m4a`、`audio/C.m4a`。
